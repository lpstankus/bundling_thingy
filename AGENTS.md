# Repository instructions

## Documentation

- Do not commit documentation files or documentation assets, including Markdown guides and screenshots. AGENTS.md is the exception for repository instructions.
- Put explanations and evidence in PR descriptions or ignored local files.

## Verification

- Do not commit automated tests or test infrastructure to this repository. This includes unit tests, integration tests, GPU tests, test fixtures, test harnesses, and CI steps that run tests.
- Verify changes with type checking, Clippy, and manual runs of the affected behavior.
- Keep one-off verification code in ignored local files.
